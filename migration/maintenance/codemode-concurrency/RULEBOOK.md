# Codemode concurrency maintenance

Use idiomatic Go. Product builds must remain CGO-free. The Go race detector may
use CGO for diagnostics only. Keep dependency versions and runtime behavior
unchanged. All generated code, comments and documentation must be in English.

Only the three registered outputs are writable. Never modify frozen independent
judges, baseline files, historical plans, receipts or session records. Preserve
all unrelated tests in the owned test file. Do not skip tests, increase timeouts
to hide ordering errors, serialize callbacks, or replace exact payload checks
with permissive assertions. Use channels or mutexes, not sleeps, for coordination.

The candidate is an implementation of a reviewed Go adaptation, not a claim of
identical JavaScript scheduling. Record the distinction plainly in NOTES.md and
the public SDK documentation.
