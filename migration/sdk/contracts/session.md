# Embedded SDK: session

Implement CreateAgentSession and AgentSession using Pith Agent/agent-loop rather than sdk.Run's small standalone loop. Assemble model/options, resources, tools, configuration and durable session manager. Prompt is synchronous until completion; only one run per session, concurrent Prompt fails immediately. Independent sessions may run concurrently. Preserve user/assistant/tool messages including thinking, images and provider metadata. Custom tools are advertised and results pair with exact call IDs. Structured Subscribe returns idempotent unsubscribe; publish agent_start/end, message_start/update/end, tool_execution_start/update/end, turn_start/end events in causal order. Listeners can inspect snapshots/unsubscribe without lock deadlock. Messages and RunResult snapshots are detached from mutable state. Return turns, stop reason and actual usage; do not fabricate cost. SetModel/SetActiveTools apply safely between requests; reject invalid changes. Support Steer and FollowUp during a run and queue semantics from source. Cancel/Abort return errors and propagate to streams/tools; Close unsubscribes and releases resources without closing a caller-owned manager. Save coherent turns and restore without replaying successful side effects. Tests must cover tool failure recovery, model changes, queue ordering, no cross-session global state, restart after completed turn, unknown tools and listener cleanup.
