# Embedded SDK: storage

Implement SessionManager with memory-only mode when path is empty and append-only durable file mode otherwise. Each message, compaction, model/thinking change and custom record has a unique ID and parent; preserve unknown JSON fields/payloads. Entries lists all entries, Context lists the active root-to-leaf branch, Branch changes the leaf durably without deleting siblings. Empty id branches to the root. Unknown IDs and cycles fail without mutation. Thread-safe append and immutable returned snapshots are required. Opening malformed complete records must fail visibly; document the crash-tail recovery policy, never silently erase a valid prefix. Check write/close errors and use mode 0600. Existing Pith JSONL/session storage can be adapted; do not rewrite existing public types. This new public API need not read every historical Pi JSONL version; explicitly document supported file version and provide rejection for unsupported formats. Candidate tests must cover reopen, leaf persistence without a subsequent append, empty sessions, branch isolation, unknown metadata, truncated records, disk failure and racing snapshots/appends. AgentSession will persist and reconstruct its model/thinking/message/compaction context using this manager.

Read the shared RULEBOOK.md and API.go.txt (available as frozen testdata/sdk-api.go.txt in the first judge). Full source ownership and dependency decisions are in the plan inventory. Every listed output is required. Prior outputs in this SDK module remain editable and cumulative judges must still pass. The original Pith baseline remains read-only.
