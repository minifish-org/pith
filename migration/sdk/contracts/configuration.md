# Embedded SDK: configuration

Implement settings and model-runtime integration, including ResolveModel, LoadSettings and SaveSettings from API.go.txt. Caller overrides > project settings > global settings. Recursively merge JSON objects, preserve false/zero/null and unknown keys; arrays replace rather than concatenate. Missing files are empty settings, malformed existing files are errors. Save atomically with private permissions. Never execute shell snippets from credentials/config by default. ResolveModel copies caller data, preserves provider/API/base URL/headers/compatibility/context and output capacity, validates positive explicit limits within model capacity, and does not hardcode 128K/4096. Preserve thinking capabilities and use an injected APIKey callback per provider. Reuse Pith catalog/auth/provider abstractions for real requests; optional OAuth token refresh uses existing auth code through an explicit caller adapter, not browser interaction. No credentials in events, logs, maps or session files. Additional candidate tests: nested null values, absent files, save interruption, invalid model overrides, concurrent independent configuration, empty/failed credential callback. Go extensions and custom models must not require shared process-wide mutation.
