# Embedded SDK: resilience

Complete long-running lifecycle behavior in AgentSession. No default max turn or wall-clock cap. Explicit MaxTurns > 0 is enforced with a clear error and persisted context. A length-truncated assistant response must NEVER execute its tool calls (even parseable ones); preserve safe history and request continuation until a non-length response or caller cancellation. RetryAttempts counts extra requests after transient 429/5xx/connection failures, with cancellable backoff; default is three retries, zero means default, negative disables. Never retry auth/invalid request failures or replay completed tool effects. Emit retry events and preserve request diagnostics without secrets. Handle terminal errors and cancellation distinctly. Before overflowing model context, compact while preserving recent complete tool-call/result pairs. Use caller Summarize when present; otherwise reuse Pith compaction with the configured provider. Reserve model output capacity, do not mutate model limits. CompactReserveTokens overrides reserve for tests; KeepRecentMessages retains at least that many messages but never splits pairs. Persist compaction summary/checkpoint so reopen restores compacted history. Failed/cancelled summarization leaves original history intact. Explicit Compact works while idle; concurrent calls fail clearly. Tests must include retry exhaustion, nonretryable errors, real cancellation during provider/tool/backoff, no partial arguments, auto/manual compaction, failed summary rollback, cancellation then next Prompt, steering/follow-up and clean Close.
