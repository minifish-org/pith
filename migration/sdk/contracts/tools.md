# Embedded SDK: tools

Implement ToolDefinition/ToolRegistry/Hooks and bridge them to existing Pith AgentTool types. Reuse read/write/edit/bash from packages/agent/harness/tools and environment; adapt grep/find/ls from coding-agent without requiring bundled ripgrep/node binaries (Go implementation or explicitly supplied backend). Default active tools are read/write/edit/bash plus custom Go tools; nil allow is default, explicit empty allow disables all, deny applies last. Validate JSON Schema before Execute, reject duplicate names and unknown activation, never invoke inactive tools. Before hook runs for every valid executable call and may deny; After runs on executed results and can transform them. Run hooks outside internal locks. Context cancellation must reach process groups/children, filesystem operations where supported and custom callbacks. Register and SetActive must not race execution and must surface model-visible declarations on the next request. Preserve result images/details/error markers. Search and read results must be bounded with explicit truncation metadata, never silently clip. File mutation queue must serialize edits to the same path. Candidate tests must cover all seven tools, exact edit mismatch, cwd, symlink handling, cancellation during bash, tool errors, duplicate registration, allow/deny precedence and before/after transformations. These are execution hooks, not an OS sandbox.

Read the shared RULEBOOK.md and API.go.txt (available as frozen testdata/sdk-api.go.txt in the first judge). Full source ownership and dependency decisions are in the plan inventory. Every listed output is required. Prior outputs in this SDK module remain editable and cumulative judges must still pass. The original Pith baseline remains read-only.

Source-map ownership (one row per export in this frozen list): `../judge/internal/conformance/sdk_incremental/testdata/owned-tools.json`. Exclude only the documented out-of-scope UI/JS-host parts; actual Go target filenames and declarations are required for implemented/adapted exports.
